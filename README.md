# Rock Paper Scissors

My rock paper scissors game. I made it three ways: a web page, a Python script and a Java program. You play the computer and try to win the match.

Play it here: https://yrockpaperscissors.netlify.app/

## The web version

It looks like a chalkboard. Pick Best of 3, 5 or 9, then click rock, paper or scissors (or press R, P or S). The tally marks keep the score, the little boxes show how each round went, and the eraser at the bottom wipes the board.

## Terminal versions

Type rock, paper or scissors. Type q to quit and it shows your final score.

## Running it

Web: open `index.html` in a browser.

Python (needs Python 3):

```
python rock_paper_scissors.py
```

Java:

```
javac RockPaperScissors.java
java RockPaperScissors
```
